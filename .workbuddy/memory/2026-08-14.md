# 2026-08-14 工作日志

## 修复「中华文明探源工程」网页项目的两个问题

### 问题1：启动网页.bat 无法启动
- **根因**：bat 文件为 UTF-8 无 BOM 编码，中文 Windows 的 cmd.exe 按 GBK(936) 解读，
  导致路径 `网页代码` 和所有中文 echo 乱码，`cd` 命令失败。
- **修复**：改存为 UTF-8 with BOM 编码；首行放 `chcp 65001 >nul`（吸收 BOM，会报一个
  无害错误），第二行 `@echo off`；并用 `for /d %%D in (*)` 动态查找含 package.json
  的子目录，避免在代码中硬编码中文路径。
- **验证**：Python subprocess 测试通过，cd 成功，package.json 找到。

### 问题2：网页图片加载不出来
- **根因**：`src/assets/images/长江/良渚遗址/` 文件夹缺失（8张良渚遗址图片未从原始
  资料库复制过来），导致 `SITE_IMAGES["良渚遗址"]` 为空，良渚相关卡片/抽屉无图。
- **修复**：从 `本地资料数据库/长江流域/长江流域-11处遗址-图片/良渚遗址/` 复制 8 张
  图片到项目 assets 目录。
- **验证**：所有本地图片（含中文文件名）和 Unsplash 外链图片均 HTTP 200 正常加载。
  Vite dev server 的 `decodeURI` 对浏览器百分号编码的 URL 处理正常。

### 其他发现
- `src/imports/` 目录下的图片文件名全是下划线（如 `____.png`），是原始中文名在某次
  文件操作中被损坏所致，但 App.tsx 中的 import 引用与实际文件名一致，不影响加载。
- 陶寺遗址、殷墟遗址、三星堆遗址 3 处无本地图片，使用 Unsplash 兜底（设计如此）。
- 系统 OEM 代码页为 936 (GBK)。
