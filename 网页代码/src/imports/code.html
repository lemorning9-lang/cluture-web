从良渚的玉琮之光，到明清的锦绣华章。长江，这条横贯东西的文明之母，以其温润而厚重的力量，滋养了中华民族延绵不绝的文化根脉。

NEOLITHIC AGE / 新石器时代

良渚遗珍：玉之神邦

公元前3300 - 2300年

良渚文明以精密的大型水利系统和等级森严的玉器礼制，构筑了东亚最早的“神权国家”。玉琮，这一内圆外方的礼器，象征着良渚人对天圆地方的宇宙认知，是长江下游文明破晓时分最耀眼的华光。

SONG DYNASTY / 大宋气象

江南水乡：诗意栖居

公元960 - 1279年

两宋时期，经济重心南移，长江三角洲成为繁华的中心。烟雨朦胧的水乡建筑，拱桥流水的空间布局，不仅是世俗生活的盛景，更是中国文人画中追求的平淡天真与疏远空灵。

MING & QING / 锦绣明清

锦绣华章：天工开物

公元1368 - 1912年

明清时期，长江中下游的手工业达到巅峰。苏绣之精微，丝绸之华美，凝聚了千年的东方美学。这一时期的工匠不仅在织造物上复刻自然之美，更将中华礼序与生活艺术完美融合。
